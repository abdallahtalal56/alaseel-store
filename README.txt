تعليمات للمبرمج — تطبيق الأصيل (نسخة أولى / أول نشر)
========================================================

المرفق بهذا المجلد:
1. index.html          → كود التطبيق الكامل (ويب) الجاهز
2. manifest.json        → ملف PWA أساسي (اسم التطبيق، الألوان، الأيقونات)
3. sw.js                → Service Worker (يخلي التطبيق يشتغل حتى بدون إنترنت جزئيًا)
4. icon-192.png / icon-512.png → أيقونات مؤقتة (استبدليهم بلوجو الأصيل الحقيقي بنفس المقاسات)
5. signing.keystore     → مفتاح التوقيع (استخدمه لبناء APK/AAB)
6. signing-key-info.txt → كلمة سر المفتاح + الـ alias + البصمات
7. assetlinks.json      → جاهز فيه بصمة المفتاح، ينرفع على الموقع
                          بمسار: /.well-known/assetlinks.json

⚠️ خطوة ضرورية قبل بناء APK/AAB:
ارفعي الملفات 1-4 (index.html, manifest.json, sw.js, icon-192.png,
icon-512.png) عالموقع (alaseel-store.pages.dev) بنفس المجلد الرئيسي
(root) — مو بس index.html لحاله. من دونهم PWABuilder رح يستمر
يعطي خطأ "Missing Name" لأنه بيدور عليهم بالموقع المباشر مش بجهازك.

ملاحظة عن الأيقونات: سويتلك أيقونات مؤقتة بسيطة (حرف A بخلفية
زرقاء غامقة) بس عشان تخلص خطوة PWABuilder. لو عندك لوجو الأصيل
الحقيقي (الدائري)، ابعتيهولي أو استبدلي icon-192.png و icon-512.png
فيه بنفس المقاسات (192×192 و512×512 بكسل) قبل ما تبني النسخة
النهائية للنشر.

ملاحظات مهمة:
- هاي أول نسخة تنشر عالمتجر (Google Play / App Store)، مفيش نسخة
  سابقة، فمفتاح التوقيع هذا هو المفتاح الرسمي من الآن فصاعدًا.
- لازم تحتفظ بنسخة من signing.keystore بمكان آمن، لأن أي تحديث
  مستقبلي للتطبيق لازم يستخدم نفس المفتاح بالضبط.
- package name المقترح: com.alaseel.store (غيّره إذا عندك تفضيل آخر،
  بس لازم يتطابق مع اللي بملف assetlinks.json).
